# FV Funding — financevinance.com

Business funding advisory website for FV Funding by Finance Vinance.

- Stack: Astro 7 (static), Sveltia CMS at `/admin/`, Netlify hosting + Netlify Forms.
- Content: `src/data/*.json`, `src/content/services/*.md`, `src/content/insights/*.md`.
- Owner's guide: see `WEBSITE-GUIDE.md`.

```
npm install && npm run dev
```
